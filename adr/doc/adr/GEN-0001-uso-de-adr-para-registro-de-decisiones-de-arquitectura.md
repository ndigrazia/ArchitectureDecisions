# ADR GEN 0001. Uso de ADR para registro de decisiones de arquitectura

## Keywords

adr, log, decisión, registro, documento.

## Status

Accepted

References [ADR GEN 0002. Formato usado en el documento ADR](GEN-0002-formato-usado-en-el-documento-adr.md)

## Context

Capturar la decisión de arquitectura junto a su contexto y consecuencias es sumamente importante. Es por ello, un  requisito fundamental contar con un documento que permita registrar sus decisiones.

## Decision

Utilizaremos ADR (Architecture Decision Record) como mecanismo de registro de las decisiones de arquitectura.

## Consequences

Si el equipo de arquitectura abandona el uso de ADR para registrar sus decisiones se pierde el contexto sobre el cual fueron tomadas las mismas.
